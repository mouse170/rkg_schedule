# Rakuten Girls 樂天女孩即時上班班表

專為台灣樂天桃猿棒球隊專屬啦啦隊 **Rakuten Girls（樂天女孩）** 打造的即時排班、看台應援輪替矩陣與席位查詢系統。

線上展示網址：[https://mouse170.github.io/rkg_schedule/](https://mouse170.github.io/rkg_schedule/)

---

## 核心特色與系統架構

1. **首頁預設當日班表與智慧日期感應**：
   - 進入網站預設載入「當日應援」主場班表，若當天有賽事即時標註「今日上班」。
   - 非當日賽事自動以週為單位換算相對時間標記（明天、後天、本週幾、下週幾）。
   - 若使用者設有最愛名單，系統自動智慧優先跳轉至最愛成員有排班的最近日期。

2. **三語系國際化支援（繁體中文、日本語、한국어）**：
   - 支援語系即時切換，完整涵蓋所有功能導覽、各局站位（東、西、大樂、專區、賽後表演）、看台席位小知識、分享彈窗與下載圖卡。

3. **雙主題配色切換與 OLED 純黑暗色模式**：
   - 提供「活力粉嫩（Idol Bloom）」淺色主題與「深邃純黑（OLED Dark）」高對比暗色模式，夜間賽事與球場現場觀看省電不刺眼。
   - 左上角品牌識別 Logo 與主題日 Banner 針對雙主題獨立適配高對比色彩。

4. **PWA 離線漸進式應用與手動快取重整**：
   - 完整支援 PWA（Progressive Web App）標準，具備 Service Worker 離線快取機制，無網路環境亦可快速檢視已載入班表。
   - 頂部狀態列提供「手動清除快取並同步最新班表」按鈕，確保球迷在球場網路環境下隨時獲取最新異動。

5. **Google 試算表即時連動與過期資料清理**：
   - 前端直連 Google Sheets 多工作表即時資料來源，動態過濾已過期的歷史賽事，嚴格與官方最新發布內容同步。
   - 自動容錯解析大小寫姓名（如 KIRA、MIKA）與各類備註格式，站位未定者簡化標註「待公佈」，排版整齊清爽。

6. **全體 27 位現役應援成員肖像與官方社群整合**：
   - 完整收錄 27 位現役成員與外籍應援女孩（河智媛、廉世彬、禹洙漢、高佳彬、金佳垠等）。
   - 標示成員背號、國籍、隊長／副隊長職責、官方 Instagram 帳號與多語系譯名一鍵複製。

7. **Stitch 雙模式緊湊型分段控制與「我的座位視角」模式**：
   - **雙模式分段切換（Dual-Mode Segmented Control）**：將「依比賽局數看」與「依座位視角看」收納為緊湊分段按鈕，篩選膠囊採用單行平滑滑動軌道（Single-Row Chip Rail），手機端垂直高度節省超過 60%。
   - **座位視角看台專區獨立標籤**：座位視角模式獨立提供「一壘東區」、「三壘西區」、「專區應援」、「大樂放鬆區」與「東R／西R舞台」標籤。
   - **嚴格分區隔離**：一壘東區與三壘西區嚴格排除專區應援成員，避免主題日專區女孩誤入一般東、西區清單。
   - **專屬時間軸分組**：依「1-3 局來到你這區」、「第 5 局下中場舞」、「7-8 局換側來到你面前」或「全場固定此區」結構化排列，卡片自動以金色聚焦外框高亮對應局數膠囊。
   - 內建桃園樂天棒球場（Rakuten Taoyuan Baseball Stadium）席位圖與換邊規則導覽，地圖分區支援點擊直達該席位視角。

8. **2D 看台輪替矩陣視圖（Matrix View）**：
   - 提供「卡片視圖」與「矩陣視圖」一鍵無縫切換。
   - **單日矩陣模式**：橫列為區域（一壘東區、三壘西區、大樂區、看台專區），直行為時段（1-3 局、中場表演、7-8 局、賽後表演），直觀呈現女孩在各時段的空間輪替。
   - **全部日期模式**：以「日期／局數／區域／看台專區」多層級樹狀展開，解決多日賽事混雜問題。
   - 各單元格內女孩嚴格落實「最愛女孩絕對置頂」排序，專區列依照看台樓層（東下、西下、東上、西上）精確排列。
   - 表格底部附設「當日未安排站位名單」，完整追蹤全員出勤狀態。

9. **分享追星班表與 9:16 限動圖卡生成**：
   - **網址參數即時同步**：支援產生包含日期與最愛名單之專屬連結（`?date=...&favs=...`），便於在社群與通訊軟體分享。
   - **9:16 Instagram 限動圖卡**：一鍵輸出高畫質 9:16 圖卡，支援當前語系文字翻譯、多日班表分層條列與日夜主題模式切換。
   - **版面安全上限與超額防護**：單日模式上限 8 位、全部日期模式上限 4 位。超過上限時自動停用圖卡下載按鈕並顯示響應式毛玻璃警示卡。
   - **彈窗內就地快速調整**：超額時直接於彈窗內顯示已選女孩之「#背號 姓名 ✕」標籤，點擊即時剔除並重新計算，無須返回首頁調整。

10. **特殊專區同時段同台配對動態**：
    - 當有 2 位（含）以上最愛女孩於同場次相同時段分配至東R、西R或大樂區等特殊站位時，卡片自動觸發流光動畫與同台徽章，並支援雙向 Hover 心跳連鎖反饋。

11. **辣酷甜主題日盛典（9/19、9/20）專屬規格**：
    - 全員 27 位出席盛典，個人專屬看台席位（東下 I～M、西下 I～K、東上 B～D、西上 B～D）全程應援。
    - 專區成員卡片標示單一金色「全場專區」膠囊；賽後表演獨立區分東、西區大合舞。
    - 依「有喜歡的女孩專區應援」、「東區、西區、大樂應援」、「其他專區應援」三層級進行優先排列。

12. **純圖形 Open Graph 社群預覽與無 Cookie 流量分析**：
    - 採用純球場看台幾何繪圖社群分享卡（1200x630，中心安全區設計），杜絕人物頭像變形。
    - 整合極輕量、無 Cookie 之 Cloudflare Web Analytics 隱私流量分析。

## GitHub Pages 部署設定

1. 將專案推送至 GitHub 儲存庫：`https://github.com/mouse170/rkg_schedule.git`。
2. 於 GitHub 儲存庫 **Settings** -> **Pages**：
   - 在 **Build and deployment** 下方的 **Source** 選擇 **GitHub Actions**。
3. 日後每次推送至 `main` 分支，GitHub Actions 自動完成編譯與部署發布。
